Embed smoke test

Manual smoke test for embed.js and the tool's auto-resize behavior. Run before any push that touches embed.js, the tool's index.html, or the vendored iframe-resizer files.

What to verify

  • Each iframe renders the Deficits and Affordability tool with branded header (logo + title) and source-line footer visible.
  • No horizontal scroll inside any of the three iframes.
  • At 480 px, the mobile breakpoint engages: cards stack, calculator collapses to single column.
  • Click Calculate after entering a loan amount — the iframe should grow to accommodate the result panel.
  • Switch from One-Time Debt Increase back to Historical Deficits — the iframe should shrink as the bill-amount field disappears.
  • DevTools Console: no errors. With data-log on the snippet (uncomment in source), iframe-resizer logs height changes.
